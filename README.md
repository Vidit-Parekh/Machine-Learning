# 🤖 Machine Learning

A collection of Jupyter Notebooks implementing core machine learning algorithms — covering supervised and unsupervised learning, model evaluation, and an end-to-end ML project.

---

## 📁 Repository Structure

| Notebook | Description |
|---|---|
| `Linear_regression.ipynb` | Simple linear regression — model fitting, cost function, and gradient descent |
| `Linear_regression_2.ipynb` | Extended linear regression with multiple features and regularization |
| `Random Forest Classification.ipynb` | Ensemble classification using Random Forest with feature importance analysis |
| `K-means.ipynb` | Unsupervised clustering using the K-Means algorithm |
| `Gini_index.ipynb` | Decision tree splitting criterion — Gini impurity explained and implemented |
| `confusion_matrix.ipynb` | Model evaluation using confusion matrix, precision, recall, and F1-score |
| `ML_project.ipynb` | End-to-end ML project applying the full pipeline from data prep to model evaluation |

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Environment:** Jupyter Notebook
- **Libraries:** NumPy, Pandas, Matplotlib, Scikit-learn, Seaborn

---

## 🚀 Getting Started

### Prerequisites

```bash
pip install numpy pandas matplotlib scikit-learn seaborn jupyter
```

### Run Locally

```bash
git clone https://github.com/Vidit-Parekh/Machine-Learning.git
cd Machine-Learning
jupyter notebook
```

Then open any `.ipynb` file to explore the implementation.
